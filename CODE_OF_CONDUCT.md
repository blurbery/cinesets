# Code of conduct

CineSets is a small project and I want it to be a friendly place to ask questions and help out.

- Be kind and patient, especially with people who are new to this.
- Keep feedback about the work, not the person.
- No harassment, insults, discrimination or personal attacks.
- Don't share other people's private details.

> [!NOTE]
> This covers issues, pull requests, reviews and anywhere else people are talking about CineSets.

If someone isn't following it, mention @blurbery in the thread and I'll deal with it. For anything serious,
also report it to GitHub with **Report content** in the comment's **...** menu. I can edit or hide comments,
lock threads and block people when I need to.
